# TestGuard — Академиялық адалдықты сақтайтын онлайн тест платформасы

Мектеп оқушыларына арналған, толық құрылымды, көп файлды онлайн тест платформасы. Vanilla HTML/CSS/JS негізінде жасалған, деректерді Google Sheets-те сақтайды.

## 1. Файл құрылымы

```
test-platform/
├── index.html              — Оқушыға арналған негізгі бет (кіру + тест + нәтиже)
├── style.css                — Барлық беттерге ортақ стиль (көк/ақ градиент дизайн)
├── script.js                 — Тест логикасы + академиялық адалдық модульдері
├── questions.json             — Сұрақтар банкі (JSON форматында)
├── admin.html                 — Мұғалім панелі
├── admin.js                   — Мұғалім панелінің логикасы
├── google-apps-script.gs      — Google Sheets-пен байланыстыратын backend скрипт
└── README.md                  — Осы нұсқаулық
```

## 2. Google Sheets пен Apps Script қосу

1. **Жаңа Google Sheets кестесін жасаңыз** (sheets.google.com → Бос кесте).
2. Мәзірден **Extensions → Apps Script** тармағын ашыңыз.
3. Ашылған редакторда тұрған үлгі кодты өшіріп, осы жобадағы **`google-apps-script.gs`** файлының толық мазмұнын қойыңыз.
4. **Сақтаңыз** (дискета белгісі немесе Ctrl+S).
5. Жоғарғы оң жақтан **Deploy → New deployment** басыңыз.
6. Түрін (Select type) **Web app** етіп таңдаңыз.
7. Баптаулар:
   - **Execute as:** Me (сіздің аккаунтыңыз)
   - **Who has access:** Anyone (кез келген адам, тіпті Google аккаунты жоқ оқушылар да жібере алуы үшін)
8. **Deploy** батырмасын басыңыз, қажет болса рұқсаттарды растаңыз (Authorize access).
9. Пайда болған **Web app URL** мекенжайын көшіріп алыңыз — ол мына түрде болады:
   `https://script.google.com/macros/s/AKfycb.../exec`

## 3. API URL-ды жобаға қою

Осы URL-ды екі жерге қою керек:

1. **`script.js`** файлында — `CONFIG.APPS_SCRIPT_URL` мәні:
   ```js
   const CONFIG = {
     APPS_SCRIPT_URL: "https://script.google.com/macros/s/ӨЗІҢІЗДІҢ_URL/exec",
     ...
   };
   ```
2. **`admin.js`** файлында — `ADMIN_CONFIG.APPS_SCRIPT_URL` мәні:
   ```js
   const ADMIN_CONFIG = {
     PASSWORD: "өз_пароліңіз",
     APPS_SCRIPT_URL: "https://script.google.com/macros/s/ӨЗІҢІЗДІҢ_URL/exec",
   };
   ```

> ⚠️ Apps Script кодын өзгерткен сайын (мысалы, бір нәрсені түзетсеңіз), **Deploy → Manage deployments → түзету (қарындаш белгісі) → New version → Deploy** арқылы қайта жариялау қажет. Web app URL әдетте өзгермейді, бірақ кодтың жаңа нұсқасы іске қосылуы үшін бұл қадам міндетті.

## 4. Мұғалім панелінің паролі

`admin.js` файлындағы:
```js
const ADMIN_CONFIG = {
  PASSWORD: "mugalim2026", // осы жерде өз паролізді қойыңыз
  ...
};
```
Бұл — клиент жағындағы қарапайым қорғаныс (тек кездейсоқ кіруден сақтайды). Егер аса маңызды деректер болса, парольді тексеруді де Apps Script жағына көшіру ұсынылады (қосымша қорғаныс қабаты).

## 5. Сайтты орналастыру (Deployment)

Файлдардың барлығы статикалық (сервер қажет етпейді), сондықтан келесі опциялардың кез келгенін қолдана аласыз:

- **GitHub Pages** — репозиторийге жүктеп, Settings → Pages арқылы іске қосу.
- **Google Sites / Google Drive + Apps Script Web App ретінде** — бірақ ыңғайлырағы GitHub Pages немесе Netlify.
- **Netlify / Vercel** — папканы drag-and-drop арқылы жүктеу жеткілікті.
- **Мектеп ішкі сервері** — файлдарды кез келген веб-серверге (мысалы, Apache/Nginx) көшіру.

Барлық файлдар бір қалтада болуы керек (`index.html`, `style.css`, `script.js`, `questions.json`, `admin.html`, `admin.js`).

## 6. Тест қалай қосылады / өзгертіледі

Сұрақтар **`questions.json`** файлында сақталады:

```json
{
  "testInfo": {
    "title": "Тест атауы",
    "durationMinutes": 30,
    "shuffleQuestions": true,
    "shuffleAnswers": true
  },
  "questions": [
    {
      "id": "q1",
      "question": "Сұрақ мәтіні?",
      "answers": ["Жауап 1", "Жауап 2", "Жауап 3", "Жауап 4"],
      "correctIndex": 0
    }
  ]
}
```

- `correctIndex` — дұрыс жауаптың `answers` массивіндегі индексі (0-ден басталады).
- `durationMinutes` — тест ұзақтығы (минутпен).
- `shuffleQuestions` / `shuffleAnswers` — сұрақтар мен жауаптарды әр оқушыға кездейсоқ ретпен көрсету.

Сұрақтарды қолмен файлда өзгертуге болады, немесе **мұғалім панеліндегі «Сұрақтар» табында** (қосу/өңдеу/өшіру/импорт/экспорт) дайындап, экспорт батырмасы арқылы жаңа `questions.json` файлын жүктеп алып, ескісінің орнына қоюға болады (браузерден сервердегі файлды тікелей өзгерту мүмкін емес — бұл барлық статикалық сайттарға тән шектеу).

## 7. Академиялық адалдық функциялары

| # | Функция | Іске асу тәсілі |
|---|---------|------------------|
| 1 | Fullscreen міндеттеу | `requestFullscreen()`, шыққанда ескерту, 3 реттен кейін автоаяқтау |
| 2 | Tab ауыстыруды бақылау | `visibilitychange`, `blur`/`focus` оқиғалары |
| 3 | Alt+Tab анықтау | `window blur` оқиғасы арқылы |
| 4 | Copy/paste/контекст мәзірі қорғау | `copy`, `cut`, `paste`, `contextmenu`, `selectstart` оқиғаларын бұғаттау + CSS `user-select:none` |
| 5 | DevTools қорғау | `F12`, `Ctrl+Shift+I/J/C` бұғатталады + терезе өлшемі эвристикасы |
| 6 | PrintScreen анықтау | `keydown` оқиғасы, экранды қараңғылату, clipboard тазалау |
| 7 | Windows+Shift+S анықтау | Комбинацияны `keydown` арқылы журналдау (толық бұғаттау мүмкін емес) |
| 8 | Мәтін таңдауды өшіру | CSS `user-select: none` |
| 9 | Zoom қорғау | `Ctrl +/-`, `Ctrl+scroll` бұғатталады |
| 10 | Бір құрылғы — бір талпыныс | `localStorage`-тегі device token |
| 11 | Refresh кезінде жалғастыру | `localStorage` автосақтау (`AUTOSAVE_KEY`) |
| 12 | Интернет үзілгенде сақтау | Офлайн кезек (`OFFLINE_QUEUE_KEY`), қосылған кезде авто-жіберу |
| 13-14 | Камера/микрофон рұқсаты | `navigator.mediaDevices.getUserMedia()` |
| 15 | Бет анықтау (қосымша) | Әдепкіде өшірулі, төменде қосу нұсқаулығы бар |
| 16 | Оқиғалар журналы | Барлық әрекет `eventLog` массивіне жазылып, Google Sheets-ке жіберіледі |

### Бет анықтауды (face detection) қосу

Бұл — қосымша (тереңдетілген) мүмкіндік, әдепкіде өшірулі, себебі ол ауыр ML модель файлдарын (бірнеше МБ) жүктеуді қажет етеді және барлық құрылғыда бірдей жылдам жұмыс істемеуі мүмкін. Қосу үшін:

1. `index.html` файлына face-api.js кітапханасын қосыңыз:
   ```html
   <script src="https://cdn.jsdelivr.net/npm/face-api.js"></script>
   ```
2. `script.js` файлындағы `CONFIG.ENABLE_FACE_DETECTION` мәнін `true` етіңіз.
3. `setupCameraAndMic()` функциясындағы белгіленген жерге face-api.js моделін жүктеу және әр бірнеше секунд сайын бетті талдау кодын қосыңыз (модель файлдарын да серверге орналастыру қажет).

## 8. ⚠️ Маңызды ескерту — қауіпсіздік шектеулері

**JavaScript арқылы браузерде 100% қорғау мүмкін емес.** Бұл — технологиялық шындық, кез келген веб-негізді тест жүйесіне қатысты:

- Оқушы екінші құрылғы (телефон, басқа компьютер) қолдана алады — мұны толықтай болдырмау мүмкін емес.
- Кейбір операциялық жүйелер мен браузерлер PrintScreen немесе Snipping Tool әрекетін JavaScript-ке толық хабарламайды — біз тек анықтай алатын оқиғаларды (пернетақта, фокус жоғалту) бақылаймыз.
- DevTools-ты анықтау эвристикалық (терезе өлшемі бойынша) әдіспен жасалады, кейбір жағдайда дәл болмауы мүмкін.
- Бет анықтау мүмкіндігі камераның сапасына, жарыққа және моделдің дәлдігіне тәуелді.

Дегенмен, бұл платформа **барынша қорғау деңгейін** қамтамасыз етеді — барлық күдікті әрекеттер журналданып, мұғалімге көрінеді, бұл өз алдына елеулі тежеуші фактор болып табылады.

## 9. Мұғалім панелінің мүмкіндіктері

- Пароль арқылы қорғалған кіру.
- Барлық нәтижелерді кесте түрінде көру, аты-жөні бойынша іздеу, сынып бойынша сүзу.
- Excel (.xlsx) және PDF форматында экспорт.
- Орташа балл, ең жоғары нәтиже, тапсырған оқушы саны, бұзушылық статистикасы.
- Ұпай бөлінісінің диаграммасы.
- Сұрақтар банкін өңдеу: қосу / өңдеу / өшіру / JSON импорт-экспорт / Raw JSON редактор.

## 10. Жергілікті тестілеу

Файлдарды кез келген жергілікті серверде ашыңыз (тікелей `file://` арқылы ашу `fetch("questions.json")` сұранысын бұғаттауы мүмкін):

```bash
# Python орнатылған болса:
python3 -m http.server 8000
# Одан кейін браузерде ашыңыз: http://localhost:8000
```
